# Vega Panel

پنل مدیریت سرویس و اشتراک — سبک، سریع و موبایل‌محور.

این پروژه یک رابط مدیریتی است برای نگه‌داری اطلاعات سرویس‌ها، کاربران، مصرف حجم،
تاریخ انقضا، کانفیگ‌ها و لینک اشتراک؛ همراه با یک ربات تلگرام اختیاری برای
استعلام وضعیت.

---

## بخش‌ها

**کاربران** — ایجاد، ویرایش، فعال/غیرفعال‌سازی و حذف کاربر به همراه سهمیه حجم و مدت اعتبار.

**مصرف** — نمایش حجم کل، مصرف‌شده، باقی‌مانده و درصد مصرف.

**کانفیگ‌ها و اشتراک** — نمایش و کپی کانفیگ‌ها و لینک اشتراک هر کاربر.

**تنظیمات** — مدیریت اطلاعات ورود، توکن ربات و پارامترهای محیطی.

**ربات تلگرام** — استعلام وضعیت سرویس برای کاربر و گزارش کلی برای مدیر.

---

## اجرا

### با Docker

```bash
docker build -t vega-panel .
docker run -d -p 8080:8080 \
  -e SECRET_KEY="یک-مقدار-تصادفی-بلند" \
  -e ADMIN_USER="admin" \
  -e ADMIN_PASS="یک-رمز-قوی" \
  --name vega vega-panel
```

### مستقیم

```bash
pip install -r requirements.txt
python app.py
```

---

## متغیرهای محیطی

| متغیر | توضیح |
|---|---|
| `SECRET_KEY` | کلید امضای نشست‌ها. حتماً مقدار تصادفی بگذارید. |
| `ADMIN_USER` | نام کاربری مدیر |
| `ADMIN_PASS` | رمز مدیر |
| `PORT` | پورت سرویس (پیش‌فرض ۸۰۸۰ در Docker) |

اگر `ADMIN_USER` و `ADMIN_PASS` تعریف نشده باشند، اطلاعات ورود از فایل
`panel_settings.json` خوانده می‌شود.

---

## نکته امنیتی

پیش از انتشار عمومی، این موارد را انجام دهید:

- مقدار `SECRET_KEY` را از حالت پیش‌فرض خارج کنید.
- رمز پیش‌فرض مدیر (`admin`) را تغییر دهید.
- سرویس را پشت یک reverse proxy با TLS قرار دهید.
